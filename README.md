# ezmc

An easy to use TUI made in Python to create and manage Minecraft servers!

## Running

```sh
python ezmc.py
```

...yeah

## Requirements

- Python 3.14+
- Java 26+

### Dependencies (see `requirements.txt`):
- requests
- pyfiglet
- textual 8+
- loguru

Install with:

```sh
pip install -r requirements.txt
```
